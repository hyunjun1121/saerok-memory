# 선행기술 검토 메모

확인일: 2026. 8. 17.

## 검토 결론

`2×2 버튼`, `화면 메뉴와 물리 키의 위치 대응`, `첫 입력 후 재입력 확정`, `큰 글자·음성 안내`, `상태에 따른 버튼 기능 변경`은 각각 오래된 공개기술에서 확인된다. 따라서 단순한 고령자용 2×2 인터페이스만으로 권리화를 시도하면 신규성·진보성 위험이 크다.

초안의 독립항은 다음 결합으로 좁혔다.

1. 물리 2×2 버튼과 화면 2×2 선택·안내 영역의 고정 공간 대응
2. 최초 입력은 보류 선택, 버튼 해제 뒤 같은 버튼 후속 입력은 확정, 다른 버튼은 종전 선택을 실행하지 않고 교체
3. 네 자리 선택 상태와 좌측 열=가역 계열·우측 열=진행 계열의 기능 축약 상태 사이 전환
4. 현재 할당 기능을 같은 2×2 위치에 동기 표시
5. 키 반복·동시 누름·해제·디바운스·설정 충돌을 상태기계 앞단에서 차단
