# 오가사 LABs 2×2 키오스크 특허출원 초안

## 파일 구성

- `오가사LABs_2x2키오스크_특허출원_검토본.pdf`: 현행 별지 제14호 앞쪽 기재본 + 명세서·청구범위 + 요약서 + 도면을 합친 28쪽 검토본
- `01_특허출원서_초안.hwp/.hwpx`: 미확정 기재사항을 표시한 편집본
- `02_명세서_청구범위.hwp/.hwpx`: 문단 64개, 청구항 18개
- `03_요약서.hwp/.hwpx`: 요약 및 대표도 표시
- `04_도면.hwp/.hwpx`: 도 1부터 도 6
- `00_출원전_확인사항.md`: 출원 전 사실 확인 목록
- `05_선행기술_검토메모.md`: 제한적 선행기술 검토와 청구항 전략

## 적용 서식

- 출원서: 2026년 5월 14일 시행 별지 제14호서식의 표·배치와 작성란 11pt를 유지
- 발명명칭: 글자 축소 없이 11pt 유지, 긴 영문명칭은 다음 줄로 배치
- 날인: 제공된 투명 PNG 도장을 출원인 서명·날인 위치에 삽입
- 명세서·요약서·도면: A4 세로, 위 40mm·왼쪽 25mm·오른쪽/아래 20mm
- 본문: 함초롬바탕 12pt, 검정, 줄간격 280%, 불필요한 장식선 제거
- 쪽번호: 첨부문서별 아라비아 숫자, 아래 여백 중앙
- 도면: 흑백 Group4 TIFF, 300dpi
- 발명의 명칭: `상태전환·이중확인형 2×2 버튼 키오스크 시스템 및 방법`

## 중요

검토본은 제출 완료 문서가 아니다. 법적 명칭, 특허고객번호, 주소, 실제 발명자, 권리승계, 심사청구, 수수료, 등록 인감과 도장의 일치 여부 및 공지예외 적용을 확정한 뒤 특허로 전자서식에서 제출해야 한다.
