# 특허출원 초안 - 출원 전 확인사항

본 문서는 2026. 8. 17. 기준 제품 구현과 현행 서식을 바탕으로 작성한 검토용 초안이다. 전자출원 또는 서면 제출 전에 아래 항목을 사실에 맞게 확정해야 한다.

## 1. 출원인 및 발명자

- 출원인의 사업자등록 또는 법인등기상 정식 명칭: `오가사 LABs`가 맞는지 확인
- 출원인의 주소와 특허고객번호
- 대표자 김현준의 서명 또는 등록 인감
- 실제 발명자 전원의 성명, 주소, 특허고객번호
- 회사가 출원인이고 개인이 발명자인 경우 특허받을 권리의 승계 근거
- 공동발명자 또는 공동출원인 누락 여부

## 2. 공개 및 공지예외 적용

- GitHub 저장소가 공중에게 실제 공개된 최초 일시
- 공개 당시 저장소 소유자와 공개 결정자
- 최초 공개 시점에 외부에서 열람 가능했던 코드, 화면, 설명의 범위
- GitHub 이전의 Vercel 배포, 발표, 영상, 지원서, 전시, 시연 또는 SNS 공개 여부
- 공개 URL, 저장소 공개 상태 기록, 커밋 페이지, 당시 코드와 화면 캡처의 보존본
- 각 공개물과 출원 발명의 구성요소 대응표

현재 확인된 관련 커밋 일자는 2026. 8. 13.이나, 커밋 일자만으로 저장소의 실제 공개일을 확정할 수 없다. 자기 공개에 해당한다면 현행 출원서의 `공지예외적용` 표시와 증명서류 제출을 출원 시점에 함께 처리하는 방안을 변리사와 확인한다.

## 3. 출원 전략

- 심사청구를 출원과 동시에 할지 여부
- 우선권 또는 원출원 존재 여부
- 국가연구개발사업 성과 해당 여부
- 수수료 감면 자격
- 국내만 출원할지, PCT 또는 해외 개별국 출원을 병행할지
- 공개된 코드로 인한 국가별 신규성 영향

## 4. 기술·권리범위 검토

- 독립항은 단순한 2×2 배열이 아니라 다음 결합을 중심으로 검토
  - 화면과 물리 버튼의 고정 공간 대응
  - 최초 입력의 보류 선택과, 버튼 해제 후 동일 버튼 후속 입력에 의한 확정
  - 다른 버튼 입력에 의한 보류 선택 교체
  - 네 자리 선택 상태와 좌·우 열 단위 기능 축약 상태의 전환
  - 현재 기능을 같은 2×2 위치에 표시하는 안내 영역
  - 반복·동시 입력·접점 튐·잘못된 설정을 차단하는 입력 안전 게이트
- 알려진 관련 공개기술과의 차이점을 변리사 선행기술조사로 보강
- 최초 명세서에 포함할 변형예와 대체 실시형태 확정

## 5. 제출 파일

- 별지 제14호서식 특허출원서
- 별지 제15호서식에 따른 명세서 및 청구범위
- 별지 제16호서식에 따른 요약서
- 별지 제17호서식에 따른 도면
- 공지예외 적용 시 관련 증명서류

이 초안은 등록 가능성, 침해 여부 또는 해외 권리 보전을 보장하지 않는다. 실제 제출 전 변리사 검토가 필요하다.
