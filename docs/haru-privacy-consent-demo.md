# Haru 개인정보 처리 안내 및 동의서

> **데모 초안 · 실제 운영용 아님**
> 실제 출시 전 운영 환경, 보유기간, 수탁업체 및 연락처를 확정하고 전문가 검토가 필요합니다.

**서비스 운영자:** 오가사 LABs
**대표자:** 김현준
**사업자 소재 국가:** 대한민국

---

## 먼저, 쉽게 알려드려요

- Haru는 이용자가 남긴 하루의 이야기와 기억을 저장합니다.
- 음성 녹음과 글 변환은 이용자가 원할 때만 사용합니다.
- 가족이나 보호자에게 자동으로 공유하지 않습니다.
- 이용자의 일기와 음성을 범용 AI 모델 학습에 사용하지 않습니다.
- 저장한 기록은 언제든 확인하거나 삭제할 수 있습니다.

## 1. 서비스 제공을 위한 개인정보 처리 안내 · 필수 확인

| 구분 | 내용 |
|---|---|
| 처리 목적 | 회원 식별, 일기 작성·저장·조회·삭제, 기억 카드 제공, 서비스 이용 기록 관리 |
| 처리 항목 | 계정 식별정보, 닉네임, 일기 내용, 작성 일시, 인물·장소·감정 등 기억 태그, 서비스 이용 기록 |
| 보유 기간 | 회원 탈퇴 또는 이용자가 해당 기록을 삭제할 때까지. 법령에 따라 보존해야 하는 정보는 해당 기간 동안 분리 보관 |
| 확인 거부 시 영향 | 서비스 제공에 필요한 최소 정보의 처리를 거부하면 회원 기능과 일기 저장 기능을 이용하기 어려울 수 있습니다. |

- [ ] 위 내용을 읽고 확인했습니다. **(필수)**

## 2. 음성 녹음 및 글 변환 동의 · 선택

| 구분 | 내용 |
|---|---|
| 이용 목적 | 음성으로 일기 작성, 음성을 글로 변환, 이용자가 말한 내용 확인 및 수정 |
| 처리 항목 | 음성 녹음 파일, 녹음 일시·길이, 음성에서 변환된 글 |
| 보유 기간 | 원본 음성은 글 변환 후 삭제하는 것을 원칙으로 합니다. 이용자가 원음 저장을 선택한 경우에는 개별 삭제 또는 회원 탈퇴 시까지 보관합니다. 변환된 글은 일기 삭제 또는 회원 탈퇴 시까지 보관합니다. |
| 동의 거부 시 영향 | 동의하지 않아도 직접 글을 입력하여 일기를 작성할 수 있습니다. |

- [ ] 동의합니다. **(선택)**
- [ ] 동의하지 않습니다.

## 3. 건강·인지 관련 민감정보 처리 동의 · 선택

이용자가 일기에 건강, 질병, 치료, 복약, 심리 상태 또는 기억 상태에 관한 이야기를 남기면 민감한 정보가 포함될 수 있습니다. Haru는 이용자가 동의한 경우에만 이러한 정보를 맞춤형 기억 질문과 일상 지원 기능에 활용합니다.

| 구분 | 내용 |
|---|---|
| 이용 목적 | 개인 맞춤형 기억 질문 제공, 일상 루틴 지원, 반복 활동에 따른 Haru 지원 신호 생성 |
| 처리 항목 | 이용자가 직접 입력하거나 말한 건강·복약·심리·인지 관련 내용, 일상 활동 기록에서 생성된 지원 신호 |
| 보유 기간 | 해당 기록의 개별 삭제, 동의 철회 또는 회원 탈퇴 시까지 |
| 동의 거부 시 영향 | 일반 일기 기능은 이용할 수 있으나 건강·인지 관련 개인화 기능과 지원 신호는 제공되지 않습니다. |

Haru의 지원 신호는 의료 진단이나 치료 결과가 아닙니다.

- [ ] 민감정보 처리에 동의합니다. **(선택)**
- [ ] 동의하지 않습니다.

## 4. 지정 가족·보호자에게 정보 공유 동의 · 선택

가족 공유는 이용자가 특정 가족 또는 보호자를 직접 연결하고 공유 범위를 선택한 경우에만 시작됩니다.

| 구분 | 내용 |
|---|---|
| 제공받는 사람 | 이용자가 직접 지정하여 연결한 가족 또는 보호자 계정 |
| 제공 목적 | 함께 보기로 선택한 일기 확인, 추억 대화 준비, 일상 지원 |
| 제공 항목 | 이용자가 공유로 설정한 일기 제목·내용·기억 태그·작성 일시 |
| 보유·이용 기간 | 이용자가 공유를 중단하거나 가족 연결을 해제할 때까지 |
| 동의 거부 시 영향 | 가족 공유 기능만 제한되며 개인 일기 기능은 계속 이용할 수 있습니다. |

- [ ] 지정 가족·보호자에게 선택한 정보를 제공하는 데 동의합니다. **(선택)**
- [ ] 동의하지 않습니다.

### 민감정보 공유 추가 동의

건강·복약·심리·인지 관련 내용과 Haru 지원 신호는 아래 동의가 있는 경우에만 지정된 가족 또는 보호자에게 공유합니다. 원본 음성은 기본 공유 대상에 포함하지 않습니다.

- [ ] 지정 가족·보호자에게 민감정보를 제공하는 데 동의합니다. **(선택)**
- [ ] 동의하지 않습니다.

## 5. AI 이용 안내

- 오가사 LABs는 이용자의 일기, 음성 및 변환된 글을 **범용 AI 모델 학습에 사용하지 않습니다.**
- 동의한 정보는 Haru 안에서 일기 정리, 기억 질문 생성, 개인화 기능 제공 목적으로만 처리합니다.
- 이용자의 정보를 광고 목적으로 판매하거나 제공하지 않습니다.
- 향후 AI 이용 목적이 달라지는 경우 변경 내용을 먼저 알리고 필요한 동의를 다시 받습니다.

## 6. 이용자의 권리

이용자는 언제든 다음 권리를 행사할 수 있습니다.

- 저장된 개인정보와 일기 확인
- 잘못된 정보 수정
- 일기·음성·변환된 글 개별 삭제
- 선택 동의 철회
- 가족 공유 중단 및 연결 해제
- 개인정보 내보내기 및 회원 탈퇴 요청

**이용 경로:** Haru 설정 → 개인정보 및 동의 관리
**개인정보 문의:** [담당 이메일 입력] / [전화번호 입력]

## 7. 다른 사람의 개인정보에 관한 안내

일기에는 가급적 다른 사람의 실명, 연락처, 주소, 병력 등 식별 가능한 정보를 적지 말고 별칭을 사용해 주세요. 다른 사람과 나눈 비공개 대화를 동의 없이 녹음하거나 공유하지 마세요.
