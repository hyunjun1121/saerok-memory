# Haru 日本実証 初回10分セッション
# Haru 일본 실증 첫 만남 10분 세션

実施手順と質問構成 版 jp-first-meeting-1.0
진행 방법과 문항 구성 버전 jp-first-meeting-1.0

一度だけ参加する高齢者を対象に、生活背景、人間関係、好み、経験を集め、後の個別の問いかけに使うためのセッションです。
한 번 참여하고 귀가하는 고령자를 대상으로 생활 배경·관계·취향·경험을 수집해 이후 개인화 질문에 활용하는 세션입니다.

全員に同じ順序で12項目を提示します。四択4項目と会話8項目で構成し、会話には共通の追加質問を一つずつ用意します。
모든 참가자에게 같은 순서로 12문항을 제시합니다. 4지선다 4문항과 음성 8문항으로 구성하고, 음성에는 공통 후속 질문을 하나씩 제시합니다.

導入30秒と終了20秒を含め、目安は9分40秒です。残り20秒を操作の余裕に充てます。実際の時間は話す速さで変わります。
도입 30초와 종료 20초를 포함해 목표 시간은 9분 40초입니다. 나머지 20초는 조작 여유로 둡니다. 실제 시간은 발화 속도에 따라 달라집니다.

## 実施前の準備
## 진행 전 준비

参加目的、録音、保管期間、後の個別利用を担当者が説明し、同意を確認します。説明と同意の時間は10分に含めません。
진행자가 참여 목적·녹음·보관 기간·후속 개인화 활용을 설명하고 동의를 확인합니다. 설명과 동의 시간은 10분에 포함하지 않습니다.

開始画面で1、2、3、4、5、6の参加者番号を選びます。7以上も入力できます。番号を再び選んでも、必ず最初から別の回として開始します。
시작 화면에서 1·2·3·4·5·6 참가자 번호를 고릅니다. 7번 이상도 입력할 수 있습니다. 같은 번호를 다시 골라도 항상 처음부터 별도 회차로 시작합니다.

例えば1番を二度選ぶと、参加者1の1回目と2回目が別のIDで残ります。前回の選択、途中の音声、滞在記録を上書きしません。
예를 들어 1번을 두 번 선택하면 참가자 1의 1회차와 2회차가 서로 다른 ID로 남습니다. 이전 선택·중간 음성·체류 기록을 덮어쓰지 않습니다.

録音、途中や録り直しの音声、回答、操作記録のPC保存への同意を確認します。個別利用の同意は別に選べます。
녹음, 중간·재녹음 음성, 답변, 조작 기록의 PC 저장 동의를 확인합니다. 개인화 활용 동의는 별도로 선택합니다.

データはこのPCのlocal-data/japan-pilotに自動保存します。回答の外部送信、自動文字起こし、自動の人物像推定は実行しません。
데이터는 이 PC의 local-data/japan-pilot에 자동 저장합니다. 답변 외부 전송·자동 전사·자동 인물 프로필 추정은 실행하지 않습니다.

## 도입 30초

これから、あなたの暮らしや好きなことを伺います。約10分です。話したくないことは飛ばせます。ご自分のペースでお話しください。
지금부터 생활과 좋아하는 것에 대해 여쭙겠습니다. 약 10분입니다. 말하고 싶지 않은 내용은 건너뛰셔도 됩니다. 편안한 속도로 말씀해 주세요.

## 共通の進め方
## 공통 진행 방법

画面の四つのボタンは、左上が1とA、右上が2とB、左下が3とC、右下が4とDです。色は赤、黄、緑、青の順です。
화면 버튼은 왼쪽 위가 1·A, 오른쪽 위가 2·B, 왼쪽 아래가 3·C, 오른쪽 아래가 4·D입니다. 색은 빨강·노랑·초록·파랑 순서입니다.

四択は一度押して選び、同じボタンをもう一度押して決定します。画面の決定ボタンも使えます。
4지선다는 한 번 눌러 선택한 뒤 같은 버튼을 다시 눌러 확정합니다. 화면의 선택 확정 버튼도 사용할 수 있습니다.

会話は、本質問、最初の録音、共通の追加質問、追加の録音の順です。短いお答えでもかまいません。
음성은 본질문·첫 녹음·공통 후속 질문·후속 녹음 순서로 진행합니다. 짧게 답해도 괜찮습니다.

会話では右側の2か4で録音開始、もう一度右で録音終了、保存後に右で次へ進みます。左側の1か3で質問の再生か録り直しを行います。
음성에서는 오른쪽 2·4로 녹음을 시작하고 다시 오른쪽으로 마칩니다. 저장 후 오른쪽으로 다음 단계로 갑니다. 왼쪽 1·3은 질문 다시 듣기 또는 다시 녹음입니다.

録音は本質問と追加質問を別々に保存します。1回の上限は60秒です。これは録音の上限であり、各項目の目標時間とは別です。
본질문과 후속 질문은 별도 음성으로 저장합니다. 한 번의 상한은 60초이며, 이는 문항별 목표 시간과 구분되는 녹음 상한입니다.

質問を一つずつ読み、返答を待ちます。誘導する具体例や、本人が話していない家族関係を付け足しません。
질문을 하나씩 읽고 대답을 기다립니다. 답을 유도하는 구체적 예나 본인이 말하지 않은 가족관계를 덧붙이지 않습니다.

飛ばす理由は、話したくない、当てはまらない、答えが出てこない、録音できないに分けます。今回の収集では、同意した途中の音声や録り直しも別々に残します。
건너뛰기 이유는 응답 건너뛰기·해당 없음·답이 떠오르지 않음·녹음 실패로 구분합니다. 이번 수집에서는 동의한 중간 음성과 재녹음도 각각 보존합니다.

## 保存内容と後の利用
## 저장 내용과 후속 활용

SQLiteのpilot.sqliteに参加者と回、回答、時刻、操作イベントを保存し、participants/参加者番号/attempt-回-ID/audioに音声を残します。
SQLite pilot.sqlite에는 참가자·회차·응답·시각·조작 이벤트를 저장하고, participants/참가자번호/attempt-회차-ID/audio에 음성을 남깁니다.

録音中も約1秒ごとに小さな音声データを保存します。終了前の音声はpartialとして残り、正常終了した録音は一つの音声ファイルにまとめます。
녹음 중에도 약 1초마다 작은 음성 데이터를 저장합니다. 마치지 못한 음성은 partial로 남고, 정상 종료한 녹음은 하나의 음성 파일로 합칩니다.

通信の再試行はイベントIDと音声の連番で重複を防ぎます。サーバーに届かなかったデータはブラウザーの送信待ち領域から再送します。
이벤트 ID와 음성 순번으로 재전송 중복을 방지합니다. 서버에 도착하지 못한 데이터는 브라우저 전송 대기 영역에서 재전송합니다.

ZIPにはsessions.json、実音声、attempts.csv、questions.csv、events.csvを含めます。参加者番号と回のIDで、同じ方の複数回の回答を結び付けます。
ZIP에는 sessions.json·실제 음성·attempts.csv·questions.csv·events.csv를 포함합니다. 참가자 번호와 회차 ID로 같은 사람의 여러 수집 회차를 연결합니다.

質問の表示と退出、選択変更、確定、録音開始と停止、録り直し、再生、画面の非表示、フォーカス、通信状態、端末環境を記録します。
문항 진입·이탈, 선택 변경·확정, 녹음 시작·중지·재녹음, 다시 듣기, 화면 숨김·포커스, 연결 상태, 기기 환경을 기록합니다.

滞在時間は画面表示からの経過時間と、表示されフォーカスがある時間に分けます。5秒ごとに途中経過を残し、最後の質問と本質問か追加質問かも保存します。
체류 시간은 화면 진입 후 경과 시간과 화면이 표시되고 포커스가 있는 시간으로 나눕니다. 5초마다 중간 시점을 남기고 마지막 문항·본질문·후속 질문 위치도 저장합니다.

キーボードとUSBの物理ボタンが同じキーを送る場合、入力元はkeyboard_or_physicalとして記録します。集中や能力を直接表す値とは解釈しません。
키보드와 USB 물리 버튼이 같은 키를 보내면 입력 출처는 keyboard_or_physical로 기록합니다. 집중도나 능력을 직접 나타내는 값으로 해석하지 않습니다.

強制終了や停電では最後の送信が間に合わない場合があります。退出イベントがなければ、最後の確認時点までの時間として記録し、正確な終了時刻を推測で埋めません。
강제 종료·전원 차단 때는 마지막 전송이 끝나지 않을 수 있습니다. 이탈 이벤트가 없으면 마지막 확인 시점까지의 시간으로 기록하고 정확한 종료 시각을 추측으로 채우지 않습니다.

本質問と追加質問はmainとfollowUpで区別します。文字起こしはnot_requested、人物情報は未確認として書き出します。
본질문과 후속 질문은 main과 followUp으로 구분합니다. 전사는 not_requested로, 인물 정보는 미확인 상태로 내보냅니다.

後で音声を文字に起こして確認する際は、情報ごとに質問番号と発言区間を残します。同居、名前、時期など不明な点を推測で補いません。
나중에 음성을 전사·확인할 때 정보마다 문항 번호와 발화 구간을 남깁니다. 동거 여부·이름·시기 등 불명확한 내용을 추측으로 채우지 않습니다.

個別利用に同意していない記録は、後の個別質問づくりから除外します。書き出したファイルの保管と削除も担当者が管理します。
개인화 활용에 동의하지 않은 기록은 이후 개인화 문항 생성에서 제외합니다. 내보낸 파일의 보관·삭제도 진행자가 관리합니다.

明示的な削除操作は選んだ一回だけを削除します。同じ参加者の他の回は残ります。書き出したZIPとバックアップは別に管理します。
명시적 삭제는 선택한 회차 하나만 삭제합니다. 같은 참가자의 다른 회차는 남습니다. 내보낸 ZIP과 백업은 별도로 관리합니다.

PCのフォルダー全体をコピーして保管するときは収集サーバーを終了してから行います。サーバー実行中はZIP書き出しを使います。
PC의 저장 폴더 전체를 복사해 보관할 때는 수집 서버를 종료한 뒤 진행합니다. 서버가 실행 중일 때는 ZIP 내보내기를 사용합니다.
