# Haru 20명 × 7일 샘플 데이터 분석 결과

## 요약

- 참여자: 20명. 1일차 시작 20명, 완료 16명.
- 음성 단계 이탈 후 익일 복귀: 14/14 (100.0%). 7일차 완료: 20명. 7일 완주: 6명.
- 음성 문항 운영 이탈: 14/140 (10.0%).
- 가장 큰 문항 이탈 집중 구간: D1_Q5, 4건/20회 제시 (20.0%).

## STT 사용성 비교

주 지표는 **사용 가능 전사율**이다. 후속 기억 단서 작성에 활용 가능한 전사를 전체 음성 문항 기준으로 계산한다.

| 조건 | 사용 가능 전사율 | CER | WER | 의미 단서 보존 | no-speech | 재시도 | 지연 p50 / p90 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| baseline_v1 | 78.6% | 21.8% | 25.9% | 78.7% | 11.4% | 21.4% | 5.5초 / 7.8초 |
| assist_v2 | 91.4% | 11.0% | 14.0% | 91.5% | 4.3% | 7.1% | 3.2초 / 5.5초 |

대응되는 70쌍에서 보정 조건의 사용 가능 전사율 변화는 +12.9%p, no-speech 변화는 -7.1%p, 중앙 지연 변화는 -2682ms다.

## assist_v2에 넣은 개선

- **빨간 파형:** 말하는 동안 입력 반응을 바로 확인하게 한다.
- **부담을 낮춘 안내:** “또박또박 말하려 애쓰지 않아도 됩니다. 평소처럼 편하게 말씀하세요.”
- **같은 Qwen 모델의 입력 보정:** haru-dc-hp80-rms-v2로 DC 제거·80 Hz high-pass·bounded RMS를 적용한다.

## 개선 후보

1. D1_Q5에서 안내·확인 단계·입력 실패 원인을 telemetry 코드별로 분리한다.
2. 음성 문항에서 권한 거부, no-speech, STT 실패, 사용자 취소를 분리하고 재시도 후 완료까지 연결한다.
3. baseline **decode-resample-only-v1**와 assist **haru-dc-hp80-rms-v2**를 동일 입력에 적용해 전사 품질 변화를 계속 확인한다.
4. 집단별 셀 n<3은 숨기고, 작은 집단 차이를 개인 원인으로 설명하지 않는다.

## 활용 기준

- 임상 상태, 질환, 인지 저하를 추론하지 않는다.
- 이탈·STT 지표는 제품 흐름과 음성 UX 개선에만 활용한다.
- 후속 데이터에서도 같은 지표와 오류 원인 코드를 유지한다.
