# 최종 프로그램 설계안: Duolingo 스타일 인지·기억 훈련 앱

## 0. 한 줄 정의

고령 사용자가 하루 5~10분 동안 사자성어, 속담, 사진, 소리, 개인 기억을 “선택형 문제”로 풀면서 언어 기억, 주의력, 회상 능력, 자기 삶의 에피소드 기억을 반복적으로 활성화하는 앱.

의료적 포지셔닝은 “치매 예방 치료제”가 아니라 “인지 건강 루틴”, “기억력 관리”, “두뇌 활동 습관”으로 시작한다.

---

## 1. 제품명 후보

1. 기억정원
2. 하루기억
3. 기억루프
4. 말랑두뇌
5. 오늘의 기억
6. 사자성어 기억학교

추천: **기억정원**

이유:

* 병원 느낌이 약하다.
* 고령층에게 부드럽다.
* 개인 기억이 쌓이는 메타포와 맞다.
* 가족 기능, 사진, 회상 기능까지 확장 가능하다.

## 2. 타깃 사용자

### 1차 타깃

* 60~80대
* 스마트폰은 쓰지만 긴 텍스트 입력은 부담스러운 사용자
* 정상 인지 또는 주관적 기억 저하를 느끼는 사용자
* 경도인지장애 가능성이 있지만 독립적으로 앱을 사용할 수 있는 사용자

### 2차 타깃

* 부모님/조부모님의 인지 건강 루틴을 돕고 싶은 가족
* 복지관, 노인센터, 치매안심센터, 방문요양기관

### 제외 또는 주의 대상

* 중등도 이상 치매로 독립 앱 사용이 어려운 사용자
* 망상, 심한 불안, 우울, 혼란이 있는 사용자
* 의료적 진단·치료가 필요한 상태의 사용자

## 3. 핵심 원칙

### 원칙 1: 입력보다 선택

앱의 기본 상호작용은 텍스트 입력이 아니라 클릭, 선택, 카드 넘기기, 순서 맞추기다.

비율 기준:

* 80% 선택형
* 15% 음성형
* 5% 자유 입력

### 원칙 2: 테스트처럼 느껴지면 실패

“틀렸습니다”보다 “다시 한번 볼까요?”가 맞다.
실패 피드백은 벌점이 아니라 힌트와 복습으로 연결한다.

### 원칙 3: 새 지식과 개인 기억을 연결

사자성어 자체를 외우게 하는 것보다, 사자성어를 사용자의 경험과 연결시키는 것이 차별점이다.

예:

* 오늘의 사자성어: 새옹지마
* 질문: “처음엔 안 좋았지만 나중엔 괜찮았던 일이 있나요?”
* 선택: 건강 / 가족 / 일 / 여행 / 친구 / 기타
* 이후 회상: “지난번 새옹지마 이야기에서 어떤 주제를 고르셨죠?”

### 원칙 4: 회상 강도는 단계적으로 올린다

처음부터 “직접 말해보세요”를 요구하지 않는다.

난이도 순서:

1. 보기 중 고르기
2. 두 보기 중 고르기
3. 사진 보고 고르기
4. 첫 글자 힌트 보고 고르기
5. 음성으로 짧게 답하기
6. 자유 회상

### 원칙 5: 의료적 과장 금지

초기 제품 문구에서는 “치매 예방”, “치매 치료”, “인지기능 개선 입증” 같은 표현을 피한다.
대신 “매일 하는 기억력 루틴”, “두뇌 활동 습관”, “가족과 함께하는 회상 놀이”로 포지셔닝한다.

## 4. 핵심 제품 루프

### Daily Session: 5~10분

#### 1단계: 오늘 인사와 컨디션 선택

화면:
“오늘 기분은 어떠세요?”

선택지:

* 좋아요
* 보통이에요
* 조금 피곤해요
* 잘 모르겠어요

목적:

* 앱 진입 부담 완화
* 기분 상태 기록
* 이후 개인화 난이도 조절

---

#### 2단계: 워밍업 문제

예시:
“오늘은 무슨 요일일까요?”

선택지:

* 월요일
* 화요일
* 수요일
* 목요일

또는:
“방금 본 숫자는?”
3초 노출: 7 2 9
선택지: 729 / 792 / 279 / 927

목적:

* 주의력 활성화
* 세션 시작 리듬 형성

---

#### 3단계: 오늘의 사자성어

예시:
“오늘의 말: 고진감래”

화면 구성:

* 큰 글씨: 고진감래
* 음성 재생 버튼
* 쉬운 뜻: “힘든 일이 지나면 좋은 일이 온다는 뜻이에요.”
* 1문장 예시

---

#### 4단계: 선택형 이해 문제

문제:
“고진감래와 가장 가까운 상황은?”

선택지:

* 오래 연습해서 드디어 노래를 잘하게 됐다
* 길에서 우연히 친구를 만났다
* 같은 말을 여러 번 반복했다
* 너무 급하게 행동했다

정답 후:
“맞아요. 힘든 시간을 견딘 뒤 좋은 결과가 온 상황이에요.”

---

#### 5단계: 개인 기억 연결

문제:
“살면서 ‘고진감래’라고 느낀 순간이 있었나요?”

선택지:

* 공부/시험
* 일/사업
* 가족
* 건강
* 취미
* 잘 모르겠어요

다음 질문:
“그때 기분은 어땠나요?”

선택지:

* 뿌듯했어요
* 마음이 놓였어요
* 감사했어요
* 힘들었어요

여기서 앱은 사용자의 선택을 개인 기억 카드로 저장한다.

---

#### 6단계: 이전 기억 회상

며칠 후 문제:
“지난번 ‘고진감래’ 이야기에서 어떤 주제를 고르셨을까요?”

선택지:

* 건강
* 가족
* 여행
* 친구

정답 후:
“맞아요. 건강 이야기를 골랐어요. 다음에는 그때 어떤 기분이었는지도 떠올려볼게요.”

---

#### 7단계: 보상

* 오늘의 물방울 +1
* 기억정원 나무 성장
* 연속 학습 streak
* “오늘 기억 3개를 잘 살렸어요”

핵심은 경쟁이 아니라 루틴 보상이다.

## 5. 문제 유형 설계

### A. 사자성어 학습형

#### 뜻 고르기

“새옹지마”의 뜻은?

* 나쁜 일이 좋은 일로 바뀔 수도 있음
* 아주 빠르게 움직임
* 말을 많이 함
* 돈을 아껴 씀

#### 상황 고르기

“다음 중 새옹지마 상황은?”

* 버스를 놓쳤지만 우연히 오랜 친구를 만났다
* 약속 시간에 늦었다
* 밥을 많이 먹었다
* 책을 샀다

#### 짝 맞추기

왼쪽: 고진감래 / 일석이조 / 동문서답
오른쪽: 힘든 뒤 좋은 일 / 하나로 두 이익 / 엉뚱한 답

#### 빈칸 고르기

“힘든 시간이 지나 좋은 일이 온다는 뜻은?”

* 고진감래
* 동문서답
* 우왕좌왕
* 자화자찬

#### 선택 회상

“지난주에 가장 즐거웠다고 고른 활동은?”

* 산책
* TV 보기
* 가족 만나기
* 장보기

#### 사람 회상

“지난번 여행 이야기에 함께 나온 사람은?”

* 아내
* 딸
* 친구
* 혼자

#### 장소 회상

“예전에 좋아한다고 한 장소는?”

* 바닷가
* 산
* 시장
* 공원

#### 감정 회상

“그때 어떤 기분이었다고 하셨나요?”

* 뿌듯함
* 편안함
* 서운함
* 기쁨

### C. 사진 기반 회상형

가족이 사진을 업로드하거나 사용자가 직접 고른 사진을 사용한다.

문제:
“이 사진은 어떤 장소였을까요?”

* 부산
* 제주
* 집 앞 공원
* 시장

문제:
“이 사진 속 사람은 누구와 관련 있나요?”

* 가족
* 친구
* 이웃
* 모임

주의:
얼굴 인식 자동 추론은 초기 MVP에서 제외한다. 가족이 직접 태그를 달게 한다.

---

### D. 속도·주의력 훈련형

#### 같은 그림 찾기

3초 안에 같은 꽃 그림 고르기.

#### 색-단어 간섭

글자는 “파랑”인데 글자색은 빨강일 때, 색깔을 고르게 한다.

#### 순서 기억

“방금 나온 순서대로 눌러보세요.”
사과 → 시계 → 꽃

초기에는 속도 압박을 약하게 둔다. 빠른 반응보다 성공 경험이 우선이다.

---

### E. 음성 보조형

기본은 선택형이지만, 가끔 짧은 음성 답변을 받는다.

예:
“그때 누구와 함께였는지 말해볼까요?”

앱은 STT로 키워드만 추출하고, 사용자의 원문 음성/텍스트 저장 여부는 명확히 동의받는다.

## 6. 개인 기억 시스템 설계

### 저장 단위: Memory Card

각 기억은 긴 일기가 아니라 구조화된 카드로 저장한다.

예시:

```json
{
  "memory_id": "m_1029",
  "created_at": "2026-05-13",
  "source": "daily_session",
  "topic": "건강",
  "linked_concept": "고진감래",
  "people": ["배우자"],
  "place": null,
  "emotion": "뿌듯함",
  "confidence": 0.84,
  "sensitivity": "personal",
  "review_schedule": ["+1d", "+3d", "+7d", "+21d"]
}
```

### 저장 원칙

* 민감한 의료 정보는 기본 저장하지 않는다.
* 사용자가 말한 내용을 그대로 저장하지 않고, 우선 선택값 중심으로 저장한다.
* 음성 원문 저장은 opt-in.
* 가족 공유는 별도 동의.
* 언제든 삭제 가능.

## 7. 적응형 반복 알고리즘

### 난이도 조절 변수

* 정답 여부
* 반응 시간
* 힌트 사용 여부
* 같은 유형 반복 실패 여부
* 세션 중 이탈 여부
* 컨디션 선택값

### Review Priority Score

간단한 MVP 공식:

```text
priority = forgetting_risk + error_weight + personal_importance - recent_success
```

* forgetting_risk: 마지막 복습 후 지난 시간
* error_weight: 최근 틀린 횟수
* personal_importance: 감정/가족/사진 연결 여부
* recent_success: 최근 맞힌 횟수

### 반복 간격

* 새 기억: 1일 후
* 한 번 맞힘: 3일 후
* 두 번 맞힘: 7일 후
* 세 번 맞힘: 21일 후
* 틀림: 당일 또는 다음 세션에 부드럽게 재등장

## 8. UX/UI 설계

### 화면 원칙

* 한 화면에 한 질문
* 선택지는 2~4개
* 버튼은 매우 큼
* 글자 크기는 기본 크게
* 대비 강하게
* 스크롤 최소화
* 상단에는 진행률만 표시
* 설정, 메뉴, 광고 요소는 숨김

### 버튼 원칙

* 최소 2열 이하
* 오답도 쉽게 취소 가능
* “다음” 버튼은 항상 같은 위치
* 타임어택은 기본 off

### 피드백 문구

나쁜 예:

* 틀렸습니다.
* 실패했습니다.
* 기억하지 못했어요.

좋은 예:

* 거의 맞았어요. 다시 한번 볼까요?
* 괜찮아요. 힌트를 드릴게요.
* 다음에 다시 만나면 더 익숙해질 거예요.

### 캐릭터

Duolingo의 owl처럼 강한 캐릭터를 둘 수 있지만, 고령층 대상이므로 너무 공격적이거나 과하게 밈화된 캐릭터는 피한다.

추천 캐릭터:

* 정원사
* 작은 새
* 나무 요정
* 손주 느낌의 안내자

## 9. 가족 기능

### 가족 앱/웹에서 가능한 것

* 사진 업로드
* 가족 관계 태그
* 추억 질문 추가
* 응원 메시지 보내기
* 사용자의 주간 루틴 확인

### 가족이 볼 수 있는 것

* 학습 연속일
* 완료 세션 수
* 사용자가 공유 허용한 기억 카드
* 감정 상태의 대략적 추세

### 가족이 보면 안 되는 것

* 사용자의 모든 답변 원문
* 민감한 건강 정보
* 공유 동의 없는 개인 회상 내용
* 진단처럼 해석될 수 있는 점수

### 콘텐츠 단위

각 사자성어는 다음 8개 asset을 가진다.

1. 표제어
2. 쉬운 뜻
3. 음성
4. 상황 예문 3개
5. 오답 보기 6개
6. 개인 기억 연결 질문 3개
7. 회상 문제 템플릿 3개
8. 이미지 프롬프트 또는 일러스트

## 11. MVP 범위

### MVP 목표

“선택형 사자성어 학습 + 개인 기억 저장 + 며칠 뒤 회상”이 실제로 retention과 engagement를 만드는지 검증한다.

### MVP 기능

* 회원가입 최소화
* 하루 세션 5분
* 사자성어 30개
* 선택형 문제 5종
* 개인 기억 카드 저장
* 간단한 spaced review
* streak
* 보호자 초대 1명
* 음성 읽어주기 TTS
* 관리자용 콘텐츠 CMS

### MVP에서 제외

* 의료 진단
* 인지 점수 리포트
* 얼굴 인식
* 자동 가족관계 추론
* 보험/병원 연동

## 18. 최종 제품 방향

이 앱의 본질은 “사자성어 교육 앱”이 아니다.

정확한 정의는:

**한국어 문화 콘텐츠를 이용해 새로운 의미를 배우고, 그 의미를 개인 기억과 연결하고, 일정 간격으로 다시 회상시키는 고령층용 인지 루틴 앱**

가장 강한 차별점은 세 가지다.

1. 타이핑 없는 Duolingo식 선택형 UX
2. 사자성어/속담/사진을 이용한 친숙한 문화 기반 학습
3. 개인 기억 카드와 spaced recall을 결합한 회상 루프

초기 MVP는 의료 앱이 아니라 즐거운 루틴 앱으로 출시하고, 데이터와 사용성 검증 후 의료기기/디지털치료기기 트랙을 별도로 판단한다.
