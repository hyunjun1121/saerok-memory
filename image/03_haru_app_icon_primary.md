# GPT Image 2 Prompt: Haru Primary App Icon

Copy and paste the full prompt below into GPT Image 2.

```text
Create a primary app icon for Haru, a warm daily memory and cognitive routine mobile app for older Korean and Japanese adults.

Product context:
Haru supports short, low-pressure activities such as number patterns, drawing practice, delayed word recall, personal story recall, language expression activities, garden rewards, and optional family/caregiver connection. The product must feel like a gentle daily routine, not a medical diagnosis tool.

The icon should be a text-free brand symbol based on a small sprout growing inside a warm sun circle. It should communicate daily routine, spring, memory growth, and emotional warmth without looking medical.

Visual requirements:
- Central symbol: a simple two-leaf sprout rising from a soft garden hill
- Background: rounded square app icon with warm cream or sun-yellow base
- Main colors: sage green, deep leaf green, warm sun yellow, cream ivory, soft coral accent, dark ink brown
- Shape language: large simple forms, rounded geometry, tactile mobile-app depth
- Detail level: readable at small sizes, clean enough for favicon and app launcher use
- Mood: gentle, hopeful, calm, accessible, friendly for older adults
- Text: no text, no letters, no numbers
- Format feel: polished 2D vector-like icon, crisp edges, subtle shadow, centered composition

Create one final icon, not a grid. Use a plain transparent or warm cream outer background if needed.

Avoid:
Any Duolingo-like bird or owl, copied trademark style, random text, fake letters, medical cross, hospital imagery, pills, brain scans, diagnostic charts, overly complex garden scene, thin lines, dark gloomy palette, photorealism, watermark, low-resolution details.
```
