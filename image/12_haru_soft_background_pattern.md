Create a seamless soft background pattern for Haru, a warm daily memory and cognitive routine mobile app for older Korean and Japanese adults.

- Palette: warm cream background, paper ivory, very light sage green, muted leaf green, pale coral, soft sun yellow

- Density: sparse and calm, not busy
- Mood: spring, memory garden, daily routine, gentle care
- Format: seamless repeating pattern if possible
- Text: no text, no letters, no numbers

Use case:
The pattern should work behind app cards, onboarding panels, presentation slides, and grant application visuals without distracting from Korean or Japanese UI text placed on top.

Avoid:
High contrast, busy wallpaper, photorealistic texture, random text, fake letters, medical symbols, diagnostic charts, copied trademark style, harsh neon colors, dark background, cluttered motifs, watermark.
