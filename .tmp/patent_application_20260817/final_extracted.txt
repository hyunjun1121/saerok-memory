【발명의 설명】




【발명의 명칭】

2×2 물리 버튼의 화면 위치 대응, 상태별 기능 축약 및 이중 확인을 이용한 고령자용

키오스크 인터페이스 시스템 및 그 제어 방법

{KIOSK INTERFACE SYSTEM USING SCREEN-POSITION CORRESPONDENCE,

STATE-DEPENDENT FUNCTION COMPRESSION, AND DUAL CONFIRMATION

OF 2×2 PHYSICAL BUTTONS, AND CONTROL METHOD THEREOF}


【기술분야】

【0001】 본 발명은 키오스크 사용자 인터페이스 및 입력 제어 기술에 관한 것으로서,

보다 구체적으로는 2행 2열로 배치된 네 개의 물리 입력 스위치와 화면상의 선택

또는 기능 안내를 공간적으로 대응시키고, 상호작용 상태에 따라 네 자리 선택 방식과

좌·우 열 단위 기능 축약 방식을 전환하며, 분리된 두 번의 입력에 의해 선택을

확정하는 키오스크 인터페이스 시스템 및 그 제어 방법에 관한 것이다.

【0002】 본 발명은 복지관, 요양시설, 공공기관, 병원 대기공간, 교육시설 또는

가정에서 고령 사용자에게 일상 회상, 언어, 순서 기억, 주의집중, 감정 기록 또는
생활 안내와 같은 비의료적 상호작용 루틴을 제공하는 장치에 적용될 수 있다. 본

발명의 적용 대상은 이에 한정되지 않으며, 제한된 수의 물리 입력으로 키오스크를

조작할 필요가 있는 사용자 전반에 적용될 수 있다.

【0003】 본 명세서에서 "슬롯"은 좌상, 우상, 좌하 및 우하 중 하나의 공간 위치를

의미하고, "보류 선택"은 사용자의 선택 의사를 화면 또는 음성으로 확인시키되 아직

응답 제출, 화면 전환 또는 외부 동작을 실행하지 않은 상태를 의미한다. "열 단위

기능 축약"은 좌측 열의 둘 이상의 버튼에 공통된 가역 계열 기능을, 우측 열의 둘

이상의 버튼에 공통된 진행 계열 기능을 배정하는 것을 의미한다.


【발명의 배경이 되는 기술】

【0004】 일반적인 터치 키오스크는 화면마다 버튼의 수, 위치, 크기 및 조작 방식이

달라질 수 있다. 사용자는 화면이 전환될 때마다 조작 대상을 다시 탐색하고, 작은

터치 영역을 정확히 눌러야 하며, 선택과 확정 또는 뒤로 가기와 다음 진행의 관계를

새로 해석해야 한다.

【0005】 이러한 방식은 시력 저하, 손 떨림, 손가락 관절의 가동 범위 제한, 터치

압력의 불균일 또는 화면 전환에 대한 적응 부담이 있는 사용자에게 오입력 가능성을

높일 수 있다. 특히 한 번의 터치가 즉시 응답 제출이나 화면 전환으로 이어지면

사용자가 잘못 누른 선택을 확인하고 바꿀 기회가 부족하다.

【0006】 물리 버튼의 수를 네 개로 제한하면 조작 대상은 단순해지지만, 선택 문항,

순서 입력, 음성 입력, 재시도 및 다음 진행을 모두 같은 네 버튼으로 처리해야 하는

문제가 발생한다. 화면 상태마다 버튼 기능을 임의로 바꾸면 버튼 수는 줄어들더라도
사용자가 현재 기능을 예측하기 어렵고, 물리 버튼과 화면 안내의 불일치가 발생할 수

있다.

【0007】 저가 스위치 또는 USB HID 입력 장치는 접점 튐, 키 자동 반복, 길게 누름,

버튼을 떼지 않은 상태의 추가 입력, 서로 다른 두 버튼의 동시 누름 또는 키와

코드의 중복 설정을 발생시킬 수 있다. 이러한 입력이 선택 확정 로직과 직접

연결되면 한 번의 물리 동작이 두 번의 논리 입력으로 해석되거나 서로 다른 동작이

연속 실행될 수 있다.

【0008】 네트워크 연결에 의존하는 키오스크는 현장 통신 장애나 원격 서비스 장애 때

루틴을 중단할 수 있다. 음성 상호작용을 제공하는 경우에도 음성 파일 또는 전사문을

항상 저장할 필요는 없으며, 진행에 필요한 최소 신호만 처리하는 구성이 요구될 수

있다.

【0009】 따라서 물리 버튼과 화면의 공간 관계를 고정하면서도 여러 상호작용 상태를

네 개의 버튼으로 처리하고, 선택 전 확인 기회를 제공하며, 각 상태의 기능을 화면에

즉시 나타내고, 불완전한 물리 입력을 실행 전에 차단하는 통합 제어 구조가

필요하다.


【발명의 내용】

【해결하려는 과제】

【0010】 본 발명이 해결하려는 제1 과제는 물리 버튼의 위치와 화면 선택지 또는 기능

안내의 위치를 일관되게 대응시켜 사용자가 화면 전환 후에도 동일한 공간 문법으로

조작할 수 있게 하는 것이다.
【0011】 본 발명이 해결하려는 제2 과제는 최초 입력을 보류 선택으로 처리하고 버튼

해제 후 동일 버튼의 후속 입력을 확정으로 처리함으로써, 선택 내용을 확인하거나

다른 선택으로 교체할 기회를 제공하는 것이다.

【0012】 본 발명이 해결하려는 제3 과제는 네 자리 선택 상태와 열 단위 기능 축약

상태를 상호작용 단계에 따라 전환하되, 좌측 열은 되돌림 계열, 우측 열은 진행

계열이라는 의미의 극성을 유지하여 네 개의 버튼으로 복수의 기능을 제공하는

것이다.

【0013】 본 발명이 해결하려는 제4 과제는 자동 반복, 동시 누름, 접점 튐, 해제 누락

및 잘못된 설정으로부터 발생하는 중복 실행을 선택 또는 상태 전이 전에 차단하는

것이다.

【0014】 본 발명이 해결하려는 제5 과제는 네트워크 또는 마이크 사용 가능 여부와

관계없이 루틴의 진행과 복구가 가능하도록 하고, 음성 파일이나 전사문을 저장하지

않는 실시형태를 제공하는 것이다.

【과제의 해결 수단】

【0015】 상기 과제를 해결하기 위한 일 실시형태의 키오스크 인터페이스 시스템은

표시부, 좌상·우상·좌하·우하 슬롯에 대응하도록 2행 2열로 배치된 네 개의 물리 입력

스위치를 포함하는 입력부, 음성 출력부, 메모리 및 프로세서를 포함한다.

【0016】 메모리는 네 슬롯 각각에 대응하는 키 값 또는 물리 코드, 디바운스 시간,

화면 상태별 버튼 기능, 선택지, 안내 문구, 음원 및 진행 기록을 저장할 수 있다.

프로세서는 설정이 정확히 네 슬롯을 포함하는지, 서로 다른 슬롯 사이에 키 값 또는
물리 코드가 중복되는지, 하나의 슬롯에 기재된 키 값과 물리 코드가 서로 다른 실제

키를 가리키는지를 검사할 수 있다.

【0017】 프로세서는 현재 상호작용 상태가 선택 상태인지, 순서 입력 상태인지, 음성

입력 상태인지, 피드백 상태인지 또는 시작·완료 상태인지를 판정한다. 선택 또는 순서

입력 상태에서는 네 개의 화면 영역을 물리 입력 스위치와 동일한 2행 2열 공간

관계로 표시한다.

【0018】 선택 상태에서 제1 물리 입력 스위치의 최초 유효 입력이 수신되면,

프로세서는 대응 옵션을 보류 선택으로 저장하고 선택된 영역의 테두리, 크기, 아이콘

또는 상태 문구를 변경하며, 선택 효과음 또는 대응 옵션의 음성 안내를 출력한다. 이

단계에서는 응답 제출이나 다음 화면 전환을 실행하지 않는다.

【0019】 제1 물리 입력 스위치가 해제된 후 디바운스 조건을 충족하는 동일 스위치의

후속 유효 입력이 수신되면, 프로세서는 보류 선택을 확정하여 응답을 저장하거나

다음 상태로 전이한다. 후속 유효 입력이 다른 스위치에서 수신되면 종전 보류 선택을

실행하지 않고 새로운 대응 옵션으로 보류 선택을 교체한다.

【0020】 선택 이외의 상태에서 프로세서는 좌측 열의 두 스위치에 공통의 제1 기능을,

우측 열의 두 스위치에 공통의 제2 기능을 배정한다. 제1 기능은 안내 다시 듣기,

취소, 처음부터 다시 또는 같은 문항 재시도와 같은 가역 계열 기능이고, 제2 기능은

시작, 정지, 응답 확정, 순서 제출 또는 다음 진행과 같은 진행 계열 기능일 수 있다.

【0021】 프로세서는 현재 각 스위치에 배정된 기능을 물리 입력 스위치와 같은 2행

2열 위치를 갖는 화면 안내 영역에 표시한다. 좌측 열의 두 스위치가 동일 기능을
수행하는 단계에서는 좌측 두 안내 영역에 동일 의미의 문구를 표시하고, 우측 열의

두 스위치에도 해당 진행 기능의 문구를 표시한다.

【0022】 입력 안전 게이트는 설정 오류가 없는 경우에만 입력 처리를 활성화하고,

조합키 또는 편집 가능한 화면 요소에서 발생한 입력을 배제하며, 키 자동 반복을

배제하고, 하나의 스위치가 눌려 있는 동안 다른 스위치의 입력을 배제할 수 있다.

또한 키다운과 대응 키업을 한 쌍으로 추적하고, 소정 디바운스 시간 내 같은 슬롯의

재입력을 배제하며, 창 포커스 상실 또는 화면 비표시 전환 시 눌림 상태를 해제할 수

있다.

【0023】 순서 입력 상태에서 프로세서는 최초 유효 입력을 현재 단계의 보류 슬롯으로

설정하고, 동일 슬롯의 분리된 후속 유효 입력으로 해당 단계를 확정한다. 이미

확정된 슬롯의 중복 선택은 배제하고, 소정 수의 슬롯이 확정되면 열 단위 검토

상태로 전환하여 좌측 열을 순서 초기화에, 우측 열을 순서 제출에 배정할 수 있다.

【0024】 음성 입력 상태에서 프로세서는 준비 단계, 입력 단계 및 검토 단계를

전이한다. 준비 단계에서는 좌측 열을 안내 재생에, 우측 열을 입력 시작에 배정하고,

입력    단계에서는   좌측   열을   취소에,   우측   열을   입력   종료에   배정하며,   검토

단계에서는 좌측 열을 다시 입력에, 우측 열을 응답 확정에 배정할 수 있다.

【0025】 음성 입력의 일 실시형태는 마이크 신호의 진폭만 실시간 시각화하고 음성

파일    또는   전사문을    저장하지   않는다.   마이크가    없거나   권한이   거부된    경우

프로세서는 대체 파형을 표시하면서 버튼 상태 전이와 루틴 완료를 계속할 수 있다.

【0026】 피드백 상태에서는 좌측 열을 동일 문항 재시도 또는 피드백 다시 듣기에,
우측 열을 다음 문항 진행에 배정할 수 있다. 완료 상태에서는 좌측 열을 완료 안내

다시 듣기에, 우측 열을 메뉴 복귀에 배정할 수 있다.

【0027】 프로세서는 응답 식별자, 선택된 옵션 또는 순서, 응답 시간 및 완료 시각을

로컬 저장소에 저장하고, 재실행 시 최초 미완료 단계부터 재개할 수 있다. 정적

애플리케이션, 음원, 글꼴 및 진행 데이터는 로컬 장치에 저장될 수 있으며 외부

네트워크 연결 없이 실행될 수 있다.

【발명의 효과】

【0028】 본 발명에 따르면 화면 선택지와 물리 버튼의 공간 관계가 유지되어 사용자가

버튼 번호나 복잡한 메뉴 경로를 암기하지 않고 위치 대응에 따라 조작할 수 있다.

【0029】 최초 입력과 확정 입력을 버튼 해제로 분리하고, 다른 버튼 입력 시 보류

선택을 교체하므로 한 번의 우발 입력이 즉시 응답 제출 또는 화면 전환으로

이어지는 것을 억제할 수 있다.

【0030】 네 자리 선택 상태와 열 단위 기능 축약 상태를 조합하므로 버튼 수를 늘리지

않고 선택, 순서, 음성, 재시도 및 진행 기능을 제공할 수 있다. 좌측의 가역 계열과

우측의 진행 계열이라는 의미를 유지하여 상태별 기능 변경의 예측 가능성을 높일 수

있다.

【0031】 입력 안전 게이트가 반복, 동시 누름, 접점 튐, 키업 불일치 및 설정 충돌을

상태기계 앞단에서 배제하므로 하나의 물리 동작이 복수의 논리 동작으로 해석되는

가능성을 낮출 수 있다.

【0032】 화면 하단의 2행 2열 안내 영역이 현재 기능과 눌림 상태를 동기 표시하고,
선택과 확정에 서로 다른 시각·음성 피드백을 제공하므로 색상만으로 상태를 구분하지

않고 현재 동작을 확인할 수 있다.

【0033】 오프라인 정적 실행과 로컬 진행 복구를 이용하면 통신 장애 중에도 루틴을

계속할 수 있다. 진폭만 처리하는 음성 실시형태는 음성 파일 또는 전사문을 만들지

않으면서 입력 중임을 시각적으로 안내할 수 있다.


【도면의 간단한 설명】

【0034】 도 1은 본 발명의 일 실시형태에 따른 키오스크 인터페이스 시스템의 구성

블록도이다.

【0035】 도 2는 2×2 물리 입력 스위치와 화면 선택 영역 및 기능 안내 영역의 공간

대응 관계를 나타내는 도면이다.

【0036】 도 3은 입력 안전 게이트가 키 입력을 유효 입력으로 정규화하는 과정을

나타내는 흐름도이다.

【0037】 도 4는 선택 상태와 순서 입력 상태에서 보류 선택 및 확정을 처리하는 상태

전이도이다.

【0038】 도 5는 시작, 음성 입력, 피드백 및 완료 단계에서 좌·우 열 단위 기능이

변경되는 예를 나타내는 도면이다.

【0039】 도 6은 오프라인 진행 저장, 재개 및 입력·마이크 오류 시의 계속 동작을

나타내는 흐름도이다.


【발명을 실시하기 위한 구체적인 내용】

【0040】 이하 도면을 참조하여 본 발명의 실시형태를 설명한다. 동일하거나 대응하는
구성요소에는 동일한 참조부호를 부여한다. 아래 실시형태는 발명을 설명하기 위한

예이며, 청구범위가 특정 하드웨어, 운영체제, 언어 또는 콘텐츠 종류로 한정되는 것은

아니다.

【0041】 도 1을 참조하면, 키오스크 인터페이스 시스템(100)은 표시부(110), 물리

입력부(120), 입력 정규화부(130), 상태 제어부(140), 음성 출력부(150), 선택적 마이크

입력부(160),   로컬   저장부(170)   및   설정   검증부(180)를   포함할   수   있다.   입력

정규화부(130), 상태 제어부(140) 및 설정 검증부(180)는 하나 이상의 프로세서가

메모리의 명령을 실행하여 구현할 수 있다.

【0042】 표시부(110)는 예를 들어 1080×1920 픽셀의 세로형 화면일 수 있고,

애플리케이션은 논리적으로 540×960 픽셀의 화면 좌표계를 사용할 수 있다. 물리

입력부(120)는 좌상 스위치(121A), 우상 스위치(121B), 좌하 스위치(121C) 및 우하

스위치(121D)를 포함한다. 네 스위치는 USB HID 키보드의 키다운 및 키업 이벤트를

출력할 수 있으나, GPIO, 직렬통신, 블루투스 또는 기타 입력 인터페이스로 대체될 수

있다.

【0043】 도 2를 참조하면, 표시부(110)의 네 선택 영역(111A, 111B, 111C, 111D)은

물리 입력부(120)의 네 스위치(121A, 121B, 121C, 121D)와 각각 좌상, 우상, 좌하 및

우하의 동일한 공간 관계를 가진다. 각 슬롯에는 A, B, C, D와 같은 식별자와 서로

다른 색상 또는 명암·무늬·형상 표지를 함께 부여할 수 있다.

【0044】 선택 영역(111A 내지 111D)은 정사각형 또는 이에 가까운 비율을 유지하고,

큰 글자, 두꺼운 테두리 및 충분한 내부 여백을 사용할 수 있다. 선택 상태는 테두리
두께, 눌림 변형, 체크 아이콘, "선택됨" 문구 및 효과음 중 둘 이상으로 표시될 수

있다. 이에 따라 색상 지각에만 의존하지 않고 보류 선택 여부를 나타낼 수 있다.

【0045】 기능 안내 영역(112A, 112B, 112C, 112D)은 표시부(110)의 하부에 2행

2열로 배치되고, 각 위치에서 대응 물리 스위치의 현재 기능을 표시한다. 물리

스위치가 눌린 동안 대응 안내 영역에는 눌림 변형 또는 강조 테두리를 표시하여

실제 입력 수신 여부를 보여줄 수 있다.

【0046】 설정 검증부(180)는 실행 시 외부 설정 파일 또는 내장 설정을 읽는다. 설정은

버전, 디바운스 시간 및 네 슬롯 각각의 키 값 또는 물리 코드를 포함할 수 있다.

설정 검증부(180)는 네 슬롯의 완전성, 키 또는 코드 형식, 슬롯 간 중복 및 같은

슬롯의 키·코드 물리 일치성을 검사한다. 검사 실패 시 입력 정규화부(130)는 임의의

기본 매핑으로 대체하지 않고 입력을 비활성화하며 오류 상태를 표시하는 폐쇄형 실패

처리를 수행할 수 있다.

【0047】 도 3을 참조하면, 입력 정규화부(130)는 키다운 이벤트를 수신한 뒤 설정

유효성, 조합키, 문자 조합 상태, 편집 가능한 요소에서의 발생 여부 및 슬롯 매핑

여부를 검사한다. 이후 자동 반복 이벤트인지, 다른 슬롯이 이미 눌려 있는지, 같은

슬롯의 직전 승인 시각으로부터 디바운스 시간이 지났는지를 검사한다.

【0048】 모든 조건을 통과한 경우에만 입력 정규화부(130)는 슬롯 하나를 유효

입력으로 상태 제어부(140)에 전달하고, 현재 눌린 슬롯 및 승인 시각을 저장한다.

대응 키업 이벤트가 확인될 때까지 같은 슬롯의 자동 반복과 다른 슬롯의 입력은

전달되지 않는다. 키업의 물리 코드 또는 정규화된 키 식별자가 키다운과 일치할 때
눌림 상태를 해제한다.

【0049】   창이   포커스를   잃거나   문서가   보이지   않는   상태로   전환되면   입력

정규화부(130)는 키업 누락에 대비하여 모든 눌림 래치를 해제할 수 있다. 디바운스

시간은 예를 들어 50ms 이상 1000ms 이하에서 설정될 수 있고, 일 실시예에서는

200ms이다.

【0050】 도 4를 참조하면, 선택 상태의 초기 단계에서 선택 슬롯은 비어 있다. 첫

유효 입력이 슬롯 A이면 상태 제어부(140)는 슬롯 A를 보류 선택으로 저장하고 선택

효과음 및 해당 옵션 음성을 출력한다. 슬롯 A가 해제된 후 다시 슬롯 A의 유효

입력이 수신되면 선택을 확정한다. 그 전에 슬롯 C가 수신되면 슬롯 A를 실행하지

않고 보류 선택을 슬롯 C로 교체한다.

【0051】 순서 입력 상태에서는 각 순서 단계마다 동일한 보류·확정 문법을 적용한다.

예를 들어 첫 번째 단계에서 슬롯 A를 한 번 누르면 슬롯 A가 보류되고, 해제 후

다시 누르면 순서 1로 확정된다. 확정된 슬롯은 중복 선택할 수 없게 하고, 다음

단계의 보류 선택을 받는다. 세 개의 슬롯이 확정되면 상태 제어부(140)는 검토

단계로 전환한다.

【0052】 순서 검토 단계에서는 선택 영역 대신 기능 안내 영역을 통해 좌측 열의 슬롯

A와 C를 "처음부터 다시"로, 우측 열의 슬롯 B와 D를 "순서 제출"로 배정한다. 좌측

열 입력은 확정 순서와 보류 상태를 초기화하고, 우측 열 입력은 순서를 제출하고

피드백 상태로 전이한다.

【0053】 도 5를 참조하면, 시작 단계에서 좌측 열은 안내 다시 듣기, 우측 열은 활동
시작에 배정될 수 있다. 음성 준비 단계에서 좌측 열은 문항 안내 다시 듣기, 우측

열은 음성 입력 시작에 배정될 수 있다. 음성 입력 단계에서 좌측 열은 취소, 우측

열은 종료에 배정되고, 검토 단계에서 좌측 열은 다시 입력, 우측 열은 응답 확정에

배정될 수 있다.

【0054】 음성 입력에 소정 최대 시간이 설정된 경우 상태 제어부(140)는 시간이

만료되면 우측 열의 종료 입력과 동일한 상태 전이를 자동 실행할 수 있다. 자동 종료

직후의 물리 입력이 검토 단계의 확정 입력으로 연속 해석되는 것을 막기 위해, 예를

들어 750ms의 보호 시간 동안 추가 입력 처리를 일시 차단할 수 있다.

【0055】 피드백 단계에서는 좌측 열을 같은 문항 재시도 또는 피드백 다시 듣기에,

우측 열을 다음 문항으로 진행에 배정한다. 하루 완료 단계에서는 좌측 열을 완료

안내 재생에, 우측 열을 메뉴 복귀에 배정한다. 세부 기능은 상태마다 달라지지만

좌측 열의 가역 의미와 우측 열의 진행 의미는 유지된다.

【0056】 음성 출력부(150)는 문항, 선택지, 단계 안내, 선택 효과음, 확정 효과음 및

완료 안내를 로컬 음원으로 출력할 수 있다. 네트워크 TTS를 사용하지 않고 사전

생성 음원을 패키지에 포함할 수 있으며, 음원이 없는 경우 화면 문구만으로 루틴을

계속할 수 있다.

【0057】 마이크 입력부(160)를 사용하는 실시형태에서 상태 제어부(140)는 입력 단계

동안 주기적으로 진폭을 계산하여 파형을 표시한다. 음성 원본, 특징 벡터 또는

전사문을 저장하지 않을 수 있다. 마이크가 없거나 접근이 거부되면 결정적으로

생성되는 대체 파형을 표시하면서 동일한 버튼 상태 전이를 유지할 수 있다.
【0058】 도 6을 참조하면, 로컬 저장부(170)는 활성 날짜, 문항 식별자, 선택 또는

순서 응답, 응답 시간 및 완료 시각을 저장할 수 있다. 애플리케이션이 종료되거나

장치가 재부팅되면 저장된 진행을 검증하고 최초 미완료 문항부터 재개한다. 특정

날짜를 명시적으로 다시 시작할 때만 해당 날짜의 응답을 초기화할 수 있다.

【0059】 일 실시형태는 Raspberry Pi 5, 세로형 디스플레이, USB HID 버튼

컨트롤러,   Chromium 키오스크   및   로컬   정적   웹   애플리케이션으로   구현된다.

애플리케이션 서버는 루프백 주소에만 열리고, 실행 중 외부 API, 원격 원문 전사,

검색 증강 생성 또는 텔레메트리를 사용하지 않을 수 있다.

【0060】 다른 실시형태에서는 네 개의 스위치에 서로 다른 돌기, 재질 또는 형상을

부여하거나 LED, 진동 또는 조명을 추가할 수 있다. 키 매핑, 디바운스 시간, 음량,

글자 크기 및 언어는 설정 파일 또는 관리자 화면에서 조정될 수 있다. 다만 네

슬롯의 공간 대응과 상태 전이 규칙은 유지된다.

【0061】 다른 실시형태에서 물리 입력부(120)는 터치 입력과 병행될 수 있다. 터치

선택과 물리 입력은 동일한 보류 선택 상태기계로 정규화될 수 있고, 입력 종류를

기록하되 사용자에게 표시되는 공간 대응과 확인 절차는 동일하게 유지될 수 있다.

【0062】 본 발명의 콘텐츠는 일상 회상, 감정, 날짜 감각, 순서 기억, 언어 또는 생활

안내를 포함할 수 있으나 특정 의학적 검사, 질병 진단, 치료 또는 예방을 의미하지

않는다. 본 발명의 핵심은 콘텐츠의 의학적 해석이 아니라 제한된 입력부에서의 상태

제어, 오입력 방지 및 공간적으로 일관된 상호작용에 있다.


【산업상 이용가능성】

및 가정용 정보 단말에 적용될 수 있다. 또한 고령 사용자뿐 아니라 손 운동 범위가

【청구항 1】

사용자에게 상호작용 루틴을 제공하는 키오스크 인터페이스 시스템에 있어서,

표시부;

좌상, 우상, 좌하 및 우하 슬롯에 각각 대응하도록 2행 2열로 배치된 네 개의 물리

입력 스위치를 포함하는 입력부;

음성 출력부;

상기 네 개의 물리 입력 스위치에 대한 입력 매핑과 복수의 상호작용 상태에 대한

상태 전이 규칙을 저장하는 메모리; 및

상기 메모리에 저장된 명령을 실행하는 프로세서를 포함하고,

동일한 2행 2열의 공간 관계로 표시하는 네 자리 선택 상태와, 좌측 열의 두 물리

입력 스위치에 공통의 제1 동작을 할당하고 우측 열의 두 물리 입력 스위치에 공통의

상기 네 자리 선택 상태에서 제1 물리 입력 스위치의 최초 유효 입력에 응답하여

대응 옵션을 보류 선택으로 저장하고 상기 대응 옵션의 확정 없이 선택 피드백을

입력이 수신되면 상기 보류 선택을 확정하고, 다른 물리 입력 스위치의 유효 입력이

수신되면 상기 보류 선택을 확정하지 않고 상기 다른 물리 입력 스위치에 대응하는

구체적 기능을 변경하되, 상기 제1 동작을 되돌림, 재생, 취소 또는 재시도 중 하나를

포함하는 가역 계열 동작으로 설정하고, 상기 제2 동작을 시작, 정지, 확정 또는 다음

진행 중 하나를 포함하는 진행 계열 동작으로 설정하며,

현재 각 물리 입력 스위치에 할당된 기능을 상기 물리 입력 스위치와 대응하는 2행

스위치의 입력을 배제하고, 상기 하나의 물리 입력 스위치의 해제 및 설정된 디바운스

시간이 충족된 후 후속 입력을 수용하도록 구성되는 것을 특징으로 하는 키오스크

인터페이스 시스템.


【청구항 2】

청구항 1에 있어서, 상기 프로세서는 실행 시 입력 설정이 상기 네 슬롯을 모두

포함하는지, 서로 다른 슬롯의 키 값 또는 물리 코드가 중복되는지, 하나의 슬롯에

설정된 키 값과 물리 코드가 같은 실제 키를 나타내는지를 검증하고, 검증 실패 시

임의 재매핑 없이 물리 입력을 비활성화하도록 구성되는 키오스크 인터페이스 시스템.


【청구항 3】

청구항 1에 있어서, 상기 네 개의 물리 입력 스위치, 상기 네 개의 옵션 영역 및 상기

2행 2열 안내 영역에는 서로 대응하는 A, B, C 및 D 식별자와, 색상·명암·무늬 또는

형상 중 적어도 하나가 공통 적용되는 키오스크 인터페이스 시스템.
【청구항 4】

청구항 1에 있어서, 상기 선택 피드백은 선택된 옵션 영역의 테두리 변화, 눌림 변형,

상태 아이콘 및 상태 문구 중 적어도 하나와, 상기 대응 옵션의 음성 안내 또는 선택

효과음을 포함하고, 상기 보류 선택의 확정 시 상기 선택 효과음과 구별되는 확정

효과음을 출력하는 키오스크 인터페이스 시스템.


【청구항 5】

청구항 1에 있어서, 상기 네 자리 선택 상태는 복수 단계의 순서 입력 상태를

포함하고, 상기 프로세서는 각 단계에서 최초 유효 입력에 대응하는 슬롯을 보류

슬롯으로 저장하고 동일 슬롯의 후속 유효 입력으로 해당 단계를 확정하며, 이미

확정된 슬롯의 중복 입력을 배제하도록 구성되는 키오스크 인터페이스 시스템.


【청구항 6】

청구항 5에 있어서, 상기 프로세서는 소정 수의 슬롯이 확정되면 상기 열 단위 동작

상태로 전환하여 좌측 열의 두 물리 입력 스위치에 확정 순서 초기화를 할당하고,

우측 열의 두 물리 입력 스위치에 확정 순서 제출을 할당하는 키오스크 인터페이스

시스템.


【청구항 7】

청구항 1에 있어서, 상기 열 단위 동작 상태는 음성 입력의 준비 단계, 입력 단계 및

검토 단계를 포함하고, 상기 프로세서는 준비 단계에서 좌측 열에 안내 재생을, 우측

열에 입력 시작을, 입력 단계에서 좌측 열에 입력 취소를, 우측 열에 입력 종료를,
검토 단계에서 좌측 열에 입력 재시도를, 우측 열에 응답 확정을 각각 할당하는

키오스크 인터페이스 시스템.


【청구항 8】

청구항 7에 있어서, 상기 프로세서는 마이크 신호의 진폭을 시각화하되 음성 파일 및

전사문을 저장하지 않고, 마이크를 사용할 수 없는 경우 대체 파형을 표시하면서 상기

준비 단계, 입력 단계 및 검토 단계의 전이를 유지하는 키오스크 인터페이스 시스템.


【청구항 9】

청구항 1에 있어서, 상기 프로세서는 문항 피드백 상태에서 좌측 열의 두 물리 입력

스위치에 동일 문항 재시도 또는 피드백 재생을 할당하고, 우측 열의 두 물리 입력

스위치에 다음 문항 진행을 할당하는 키오스크 인터페이스 시스템.


【청구항 10】

청구항 1에 있어서, 상기 프로세서는 키다운 이벤트와 물리 코드 또는 정규화된 키

식별자가 일치하는 키업 이벤트를 한 쌍으로 추적하고, 창 포커스 상실 또는 화면

비표시 전환 시 눌림 상태를 해제하는 키오스크 인터페이스 시스템.


【청구항 11】

청구항 7에 있어서, 상기 프로세서는 소정 음성 입력 시간이 만료되면 입력 종료 상태

전이를 자동 실행하고, 자동 실행 후 소정 보호 시간 동안 물리 입력을 차단하여 입력

종료가 응답 확정으로 연속 해석되는 것을 방지하는 키오스크 인터페이스 시스템.


【청구항 12】
청구항 1에 있어서, 상기 프로세서는 상호작용 루틴의 진행 상태를 로컬 저장부에

저장하고 재실행 시 최초 미완료 단계부터 재개하며, 외부 네트워크 연결 없이 정적

애플리케이션과 로컬 음원을 이용하여 상기 상호작용 루틴을 진행하는 키오스크

인터페이스 시스템.


【청구항 13】

2행 2열로 배치된 네 개의 물리 입력 스위치와 표시부를 포함하는 키오스크의 제어

방법에 있어서,

현재 상호작용 상태에 따라 네 자리 선택 상태 또는 열 단위 동작 상태를 결정하는

단계;

상기 네 자리 선택 상태에서 네 개의 화면 옵션을 상기 물리 입력 스위치와 동일한

2행 2열의 공간 관계로 표시하는 단계;

최초 유효 입력에 대응하는 옵션을 실행하지 않고 보류 선택으로 설정하여 시각 또는

음성의 선택 피드백을 출력하는 단계;

상기 최초 유효 입력의 물리 입력 스위치가 해제된 후 동일 스위치의 후속 유효

입력이면 상기 보류 선택을 확정하고, 다른 스위치의 유효 입력이면 상기 보류 선택을

확정하지 않고 교체하는 단계;

상기 열 단위 동작 상태에서 좌측 열의 두 스위치에 공통의 가역 계열 동작을, 우측

열의 두 스위치에 공통의 진행 계열 동작을 할당하고, 상태 단계에 따라 각 동작의

구체적 기능을 변경하는 단계;

현재 할당된 기능을 상기 물리 입력 스위치와 대응하는 2행 2열 안내 영역에
갱신하는 단계; 및

자동 반복 입력, 하나의 스위치가 눌린 동안의 다른 스위치 입력 및 설정된 디바운스

시간 내의 재입력을 차단하는 단계를 포함하는 키오스크 제어 방법.


【청구항 14】

청구항 13에 있어서, 상기 보류 선택을 설정하는 단계는 대응 옵션의 음성 안내를

출력하는 단계를 포함하고, 상기 보류 선택을 교체하는 단계는 종전 보류 선택에

대응하는 응답 제출 또는 화면 전환을 실행하지 않는 키오스크 제어 방법.


【청구항 15】

청구항 13에 있어서, 복수 단계의 순서 입력에서 각 단계마다 동일 슬롯의 분리된 두

번의 유효 입력으로 슬롯을 확정하고, 소정 수의 슬롯 확정 후 좌측 열 입력에 따라

확정 순서를 초기화하거나 우측 열 입력에 따라 확정 순서를 제출하는 단계를 더

포함하는 키오스크 제어 방법.


【청구항 16】

청구항 13에 있어서, 실행 시 네 슬롯의 키 값 및 물리 코드의 완전성, 중복 및 물리

일치성을 검증하고, 검증 실패 시 임의의 기본 매핑을 적용하지 않고 물리 입력

처리를 비활성화하는 단계를 더 포함하는 키오스크 제어 방법.


【청구항 17】

프로세서에 의해 실행될 때 청구항 13의 각 단계를 수행하도록 하는 명령을 저장한

비일시적 컴퓨터 판독가능 기록매체.
【청구항 18】

청구항 17에 있어서, 상기 명령은 상호작용 루틴의 진행 상태를 로컬 저장부에

저장하고 재실행 시 최초 미완료 단계부터 재개하며, 외부 네트워크 연결 없이 상기

상호작용 루틴을 진행하도록 하는 비일시적 컴퓨터 판독가능 기록매체.

【요약】




본 발명은 네 개의 물리 버튼만으로 고령 사용자의 키오스크 조작을 단순화하는

인터페이스 시스템 및 제어 방법에 관한 것이다. 물리 버튼과 화면 선택지를 동일한

2×2 공간 관계로 대응시키고, 최초 입력은 보류 선택과 시각·음성 피드백만 수행하며,

버튼 해제 후 동일 버튼의 후속 입력으로 확정한다. 다른 버튼이 입력되면 종전 보류

선택을 실행하지 않고 교체한다. 선택 이외 상태에서는 좌측 열에 되돌림 계열, 우측

열에 진행 계열 기능을 공통 배정하고 단계별 세부 기능과 2×2 안내를 동기

갱신한다. 또한 반복 입력, 동시 입력, 접점 튐 및 잘못된 키 설정을 차단하여 제한된

입력부에서도 일관된 상태 전이와 오입력 억제를 제공한다.
