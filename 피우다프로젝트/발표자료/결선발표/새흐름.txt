Haru 결선발표 새 흐름

목적
- 8분 안에 처음 Haru를 보는 심사위원에게 문제, 제품, 구현, 실증, 사업화, 팀 실행력을 순서대로 설득한다.
- 발표 종료 시 Haru를 "네 개의 물리 버튼으로 매일의 기억을 남기고, 보호자·복지관·의료 상담을 잇는 기관형 키오스크"로 기억하게 한다.
- 본문은 사용자 가치와 작동 원리만 설명한다. 모델명, 처리 상수, 데이터 구조, API, 테스트 범위는 Appendix에서 설명한다.

평가항목 대응
- 기획능력: 2~5쪽 문제·대안·경쟁·사용 흐름 확인
- 개발능력: 6~8쪽 2×2 하드웨어·42개 활동·음성 및 개인 기억 구조
- 구현 및 유용성: 6~9쪽 실제 목업·서비스 화면·독립 실증 준비
- 파급성: 3·10·11쪽 이해관계자 가치·기관 사업화·한일 확장
- 팀워크: 12쪽 역할 분담·직접 구현·상시 공동 개발 환경
- 발표: 중간발표의 시각 체계 계승·실물 영상·명확한 사실 경계

공통 제작 원칙
- 화면비: 16:9
- 시각 기준: 중간발표의 따뜻한 크림 배경, 짙은 갈색 본문, 코랄 핵심어, 보조 녹색·겨자색
- 구조 기준: 상단 영문 섹션 라벨, 한 줄 명사형 제목, 한 줄 명사형 부제목, 얇은 하단 선, 브랜드 푸터, 페이지 번호
- 표지와 마지막 장을 제외한 QR 반복 제거
- 제목과 부제목은 항상 명사형
- 본문 문구는 짧은 문장 또는 짧은 명사구
- 이미지·영상에는 별도 배경 카드 없이 직접 1pt 중성 테두리 적용
- 본문 기술 설명: 사용자 문제 → 해결 원리 → 제품 가치
- Appendix 기술 설명: 실제 구현 → 검증 범위 → 미검증·후속 범위
- 의료적 진단·공식 검사·효과 입증 표현 금지
- 공식 검사 문항·점수·판정 기준 복제 금지

본문 12장 / 7분 25초

1쪽. 표지 / 25초
제목: Haru, 네 개 버튼 기억 루틴 키오스크
부제목: 어르신·가족·복지·의료를 잇는 일상 기록

핵심 메시지
- 검사처럼 느껴지지 않는 짧은 일상 루틴
- 작동하는 2×2 물리 버튼 키오스크와 별도 로컬 기억 기술

화면 구성
- 왼쪽: Haru 로고, 제목, 부제목, 팀 오가사·충청권
- 오른쪽: 실제 목업 사선 사진을 크게 배치
- 하단 작은 문구: "오늘의 이야기가 내일의 문항과 다음 대화의 단서로"
- QR은 실제 결선용 데모 주소 확정 후 1개만 배치

사용 자산
- 목업\실물_사선.jpeg
- 중간발표 1쪽 로고·제목 구조

발표 핵심
"Haru는 어르신이 화면과 같은 위치의 네 버튼으로 하루 활동을 수행하고, 그 기록을 다음 문항과 상담 준비에 활용하는 기관형 키오스크입니다."

사실 경계
- 현재 실물 목업과 고정 7일 앱은 작동함
- STT·개인 기억 백엔드는 별도 로컬 구현이며 Pi 앱과 현장형 통합 마무리 단계


2쪽. 문제인식 / 40초
제목: 초고령사회와 돌봄의 일상 기록 공백
부제목: 치매 인구 증가·가족 부담·기관 반복 관찰의 한계

핵심 메시지
- 고령인구와 치매 환자는 증가하지만, 일상의 작은 변화를 매일 기록할 수단은 부족함
- 가족은 가끔의 전화, 기관은 수기와 반복 문답에 의존함

화면 구성
- 중간발표 2쪽의 3열 구조 재사용
  1) 가족·보호자: 매일의 안부와 변화 확인의 어려움
  2) 어르신: 검사 낙인과 스마트폰 조작 부담
  3) 복지·의료기관: 반복 문답·기록·관찰 인력의 한계
- 하단 통계 3개
  1) 한국 65세 이상 20.3% / 2025
  2) 한국 추정 치매 환자 101만 명 / 2026 전망
  3) 일본 65세 이상 29.4% / 2025
- 보조 근거: 지역사회 치매 환자 가족 45.8%의 돌봄 부담

시각 자료
- 중간발표 2쪽 레이아웃
- 새 통계는 숫자 중심 네이티브 타이포그래피

발표 핵심
"Haru가 해결하려는 문제는 진단을 대신하는 일이 아니라, 진단과 상담 이전에 사라지는 일상 기록을 남기는 일입니다."

출처
- 국가데이터처, 2025 고령자 통계: https://kostat.go.kr/board.es?act=view&bid=10820&list_no=438832&mid=a10301060100
- 보건복지부, 2023년 치매역학조사 및 실태조사 결과: https://www.mohw.go.kr/board.es?act=view&bid=0027&list_no=1484959&mid=a10503010300
- 일본 총무성 통계국, 2025 고령자 통계: https://www.stat.go.jp/data/topics/topi1460.html


3쪽. 제품 인트로 / 30초
제목: 네 주체를 잇는 하루 3~5분 루틴
부제목: 어르신 활동·보호자 안부·복지관 운영·의료 상담 준비

핵심 메시지
- Haru는 한 사람의 짧은 활동을 네 이해관계자에게 다른 가치로 전달함

화면 구성
- 중간발표 3쪽의 중앙 Haru + 4방향 연결 구조 재사용
- 중앙: Haru / 하루 3~5분 목표
- 좌상: 어르신 / 큰 글씨·네 버튼·음성 안내
- 우상: 보호자 / 점수가 아닌 안부와 대화 단서
- 좌하: 복지관 / 반복 활동 운영과 참여 확인
- 우하: 의료·상담 / 진료 전 참고 가능한 변화 기록

발표 핵심
"어르신에게는 쉬운 활동, 보호자에게는 안부, 복지관에는 운영 기록, 의료진에게는 상담 준비 자료가 됩니다."

사실 경계
- 3~5분은 제품 목표 시간이며 실제 독립 사용자 실측 평균이 아님
- 의료기관에는 진단 결과가 아니라 사용자가 동의한 관찰 기록만 제공하는 방향


4쪽. 경쟁사 분석 / 35초
제목: 기관 운영과 개인 기억을 잇는 Haru의 위치
부제목: 개인 앱·일회성 활동 중심 대안과의 구조적 차이

핵심 메시지
- 기존 대안은 검사, 앱, 돌봄기기, 기관 프로그램 중 한 역할에 집중함
- Haru는 기관 설치형 접근성과 사용자 기록 재사용을 함께 지향함

화면 구성
- 기존 중간발표 7쪽의 체크표를 삭제하고 2축 포지셔닝 맵으로 교체
- 참고 형식: 발표자료\경쟁사비교맵.jpeg의 중앙 십자축과 분산 배치 원리
- X축: 개인 스마트폰·URL 사용 → 기관 설치·운영
- Y축: 일회성 활동·점수 → 축적 기억·다음 대화
- 비교 범주
  1) 인지 선별도구
  2) 두뇌게임 앱
  3) 돌봄로봇
  4) 기관 집단 프로그램
  5) Haru 현재
  6) Haru 통합 목표
- 다른 범주는 저채도 원, Haru는 코랄 원
- Haru 현재와 통합 목표를 구분하여 개인화 자동 통합 완료 과장 방지
- 오른쪽 작은 근거 3줄
  1) 2×2 물리 버튼의 매일 루틴
  2) 응답 근거의 다음 문항·상담 재사용
  3) 어르신·보호자·상담사·기관 연결

하단 경계
- 범주 수준 구조 비교
- 효과·가격·시장우위 수치 아님
- 실제 브랜드 사용 시 공식 제품 자료와 조회일을 노트에 기록

사용 금지
- 자동차 로고·SM Insight 워터마크·파란 손글씨
- "Haru만 가능"·"경쟁사에는 개인화가 전혀 없음" 같은 절대 표현


5쪽. 20명 사용 흐름 확인 / 40초
제목: 지인 20명 사용 흐름 확인에서 얻은 제품 전환
부제목: 모바일 URL의 막힘에서 2×2 실물 키오스크까지

핵심 메시지
- 초기 웹을 사용자에게 보여준 뒤, 문제를 사용자 탓이 아닌 제품 구조의 문제로 정의함

화면 구성
- 왼쪽: 초기 모바일 화면 1~2개
- 중앙: 지인 20명 / URL 접속 / 주요 문항 수행 / 막힘 기록
- 오른쪽: 실제 키오스크 정면 사진과 2×2 화면
- 하단 관찰 → 변경 4줄
  1) 작은 화면 → 큰 세로 화면
  2) 터치·메뉴 부담 → 네 개 물리 버튼
  3) 듣는 상태 불명확 → 붉은 듣기 상태·반응 파형
  4) 인식 실패 체감 → 재시도·실패 비차단 구조

사용 자산
- 중간발표 모바일 화면
- application_assets의 실제 말하기 화면
- 목업\실물_정면.jpeg

발표 핵심
"20명 확인의 결론은 더 큰 앱이 아니라, 스마트폰 사용을 전제로 하지 않는 별도 기기였습니다."

필수 하단 문구
- 지인 기반 기능·사용성 형성평가
- 독립 대상자 연구·효과 검증 결과 아님

사실 경계
- 성공률·정확도·이탈률 수치 사용 금지
- VoiceUX 자료의 가상 20명·140세션은 실제 20명과 분리하여 Appendix에서만 제시


6쪽. 2×2 상호작용 / 40초
제목: 화면과 물리 버튼의 2×2 위치 일치
부제목: 선택·재입력 확정·음성 안내의 단일 규칙

핵심 메시지
- 기억해야 할 조작법은 네 위치와 같은 버튼 한 번 더 누르기뿐임

화면 구성
- 왼쪽: 실제 Day 1 기분 화면의 2×2 선택지
- 중앙: 화면 A·B·C·D와 실물 네 버튼의 위치 연결
- 오른쪽: 실제 목업 정면 또는 버튼 근접 사진
- 하단 4단계
  1) 음성 안내
  2) 같은 위치 누름
  3) 화면 선택 확인
  4) 같은 버튼 재입력 확정
- 실제 9.5초 동작 영상 자동재생

사용 자산
- 목업\실물_작동영상.mp4의 선택→확정→다음 문항 구간
- 목업\실물_정면.jpeg
- 현재 Pi 화면 캡처

발표 핵심
"버튼의 의미를 외우는 대신, 화면에서 보이는 위치를 그대로 누르게 했습니다."

권리화 메시지
- 2×2 고정 위치와 선택·재입력 확정 구조의 특허 출원 진행
- 등록·권리 확보 완료 표현 금지


7쪽. 콘텐츠 완성도 / 40초
제목: 하루 6개·7일 42개 일상 기억 루틴
부제목: 기분·요일·기억·계산·말하기·순서 활동

핵심 메시지
- 한 화면에 하나의 활동을 두고, 같은 조작 규칙으로 매일 반복함

화면 구성
- 발표자료\문항소개랑 예시화면 예시1.jpeg의 3×2 구성 계승
- 실제 Day 1 기준 여섯 활동
  1) 기분
  2) 요일
  3) 개인 기억
  4) 생활 계산
  5) 오늘의 장소·활동 말하기
  6) 세 단어 순서 기억
- 각 영역에는 짧은 설명과 실제 화면 썸네일 1개
- 하단: 7일 × 하루 6개 = 42개

표현 규칙
- "사용자 맞춤형 CIST·MMSE 문항" 사용 금지
- "CIST·MMSE가 다루는 인지 영역을 참고한 Haru 자체 활동"으로 한정
- 공식 검사 문항·배점·판정·컷오프 복제 없음
- 진단·공식 인지검사가 아닌 일상 루틴

발표 핵심
"검사를 복제한 것이 아니라, 기억·주의·언어·시간·순서 같은 영역을 일상 문항으로 다시 설계했습니다."


8쪽. 개발 완성도 / 45초
제목: 한 번의 응답이 다음 대화로 이어지는 구조
부제목: 음성 기록·개인 기억 재사용·보호자 및 전문가 리포트

핵심 메시지
- 개인화는 AI가 추측하는 일이 아니라 사용자가 남긴 기록을 다시 찾는 과정임

화면 구성
- 발표자료\문항소개랑 예시화면 예시2.jpeg의 4단계 흐름 계승
- 스마트폰 프레임을 현재 제품 구조로 교체
  1) 2×2 일상 활동
  2) 말한 내용의 확인 가능한 기록
  3) 관련 기억 기반 다음 문항 초안
  4) 보호자 안부·전문가 상담 준비
- 실제 서비스 화면 4개를 연속 배치
  1) 시작 화면
  2) 2×2 문항 화면
  3) 말하기 파형 화면
  4) 보호자·상담사 연결 또는 리포트 화면
- 하단 상태 3줄
  1) Pi 키오스크: 고정 7일 오프라인 루틴 구현
  2) 별도 로컬 서비스: 음성 기록·개인 기억 검색·문항 초안 구현
  3) 9월: 현장형 통합 마무리

본문 설명 수준
- 음성: 작은 목소리와 긴 쉼을 살리고 실패가 활동 중단으로 이어지지 않는 원리

A03. 2×2 상호작용 상태 기계

A07. 한국어 STT 모델 채택 근거
부제목: 공개 벤치마크·로컬 실행·강제 정렬·검증 한계

A08. STT 입력 안정화와 런타임 계약
