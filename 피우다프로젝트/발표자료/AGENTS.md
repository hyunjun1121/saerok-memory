## 산출물

- 새 파일명: `결선발표\Haru_결선발표_새흐름_최종.pptx`
- 기존 `결선발표\Haru_결선발표_START-UP_STYLE.pptx`는 참고본이다. 덮어쓰지 않는다.
- 중간 산출물, 렌더, 임시 파일은 발표자료 폴더 밖의 작업용 임시 디렉터리에 둔다.
- 최종 폴더에는 최종본 한 개만 추가한다. `v2`, `v3`, `final-final` 같은 중복본을 남기지 않는다.

## 제작 도구

- PPTX 생성·편집에는 `presentations:Presentations` 스킬을 사용한다.
- 스킬이 요구하는 `load_workspace_dependencies`와 `@oai/artifact-tool` 런타임을 사용한다.
- 해당 런타임이 제공되지 않으면 제작을 우회하지 말고 정확한 blocker를 보고한다.
- `python-pptx`, 구형 Python artifact API, PowerPoint COM을 대체 제작 경로로 사용하지 않는다.
- 기존 PPTX가 시각 기준이므로 Presentations 스킬의 template-following 절차를 따른다.

## 검증 절차

최종본 전달 전 반드시 수행한다.

1. 모든 원본 PPTX의 관련 슬라이드를 직접 검사한다.
2. 최종 24장을 전부 렌더한다.
3. 각 슬라이드를 전체 크기로 개별 확인한다.
4. 제목·부제목 줄바꿈, 텍스트 잘림, 겹침, 이미지 왜곡, 영상 재생, 외곽선 통일을 확인한다.
5. 본문 12장의 발표 시간을 합산해 445초인지 확인한다.
6. 모든 슬라이드 발표자 노트에 `[Sources]`를 둔다.
7. 본문에는 `[Timing]`, Appendix에는 `[Appendix]` 메타 정보를 둔다.
8. 외부 통계·벤치마크·이미지 출처는 URL과 조회일을 노트에 기록한다.
9. PPTX ZIP·XML·relationship·media·notes 무결성을 검사한다.
10. unresolved placeholder가 있으면 사용자에게 명확히 보고한다.
