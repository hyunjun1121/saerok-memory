Korean narration uses Qwen's built-in Sohee voice except for the 32 Day 1
entries declared by manifest.json audioOverrides. Twenty-eight entries use the
previously selected B/right Fish Audio browser exports. Four mood-option entries
use the maintainer's final choices from calm-mood-candidates/selections.json.
Japanese narration uses Qwen's built-in Ono_Anna voice for the regular manifest.
The Day 1 overlay (ja/day1/manifest.json) contains thirty-two maintainer-selected
Fish Audio exports, including the NFC login waiting clip, using the veteran voice
and gentle double pauses.
No model id, revision, or license is asserted for the Fish Audio exports because
those values are not embedded in the downloaded MP3 files. See
tools/fish-day1-browser/day1-runtime-import.json and
tools/fish-day1-browser/calm-mood-candidates/calm-mood-runtime-import.json for
exact source hashes and runtime mappings. Confirm applicable Fish Audio terms
before redistribution or commercial release.

No cloned voice or third-party reference recording is used by the Qwen source.

Model weights and generation runtime are development-only and are not shipped
to Raspberry Pi. This directory contains only generated Ogg Opus narration and
the local runtime manifest.
