# Japanese Day 1 Fish Audio selector

Day 1 の日本語31文を、Fish Audio の3音声（`ank0`、`田中みなみ風`、`女性アナウンサー（ベテラン）`）で聞き比べるためのローカル画面です。

## 起動

`raspberry-pi-demo` から次を実行します。

```powershell
node tools/fish-day1-browser/ja/server.mjs 4194
```

ブラウザで `http://127.0.0.1:4194` を開き、各文の音声を再生して一つ選びます。選択結果は同じフォルダーの `day1-selections.json` に即時保存されます。

## 起動時の第一声

画面上部に、開始直後の文 `春子さん、今日の気分はいかがですか。` を4つのタグスタイル、3つの声で比較する12枠を表示します。`start-greeting-inventory.json` がタグと音声ファイルの対応表です。`audio/intro_greeting_*.mp3` が存在する候補は再生でき、未生成の候補は「生成待ち」と表示されます。

高齢者向けの候補では、名前を聞き取りやすくする短い間、質問の前後の短い間、控えめな強調だけを使い、笑い声や急な効果音は使いません。

## 現在の Day 1 採用音声

全31文は `女性アナウンサー（ベテラン）` を採用し、`[short pause]` を自然な区切りに2回配置した `gentle_double_pause` 形式で生成済みです。`day1-selections.json` は31文すべてを `veteran` に選択済み、`day1-inventory.json` に各文の `taggedText` を記録しています。実行用音声はリポジトリの `public/assets/audio/narration/ja/day1/` に取り込まれています。

`exercise.D1_Q3.option.A` は画面では `長野県松本市` と表示し、音声入力だけ `ながのけん・まつもとし` としています。漢字の地名が中国語のように聞こえないよう、読みをひらがなで指定しています。

## 音声生成の順序

1. `day1-inventory.json` の最初の未完了文を Fish Audio に貼り付けます。
2. 音声候補を一つ選び、`全体自動タグ`、`音声生成` の順に押します。
3. 生成された音声をダウンロードフォルダーから `audio/` の指定名へ移動します。
4. 同じ文で残り2音声も生成し、3ファイルがそろったら次の文へ進みます。

ファイル名と文章の対応はインベントリを正本とします。日本語の円表記・日本人名・日本語の句読点を韓国語のまま戻さないでください。
